# sandbox-3

A skills-pack source: skills live in [`skills/`](skills/), grouped for
discovery by packs in [`packs/`](packs/).

## Install

```bash
sp source add github:anant-acog/sandbox-3   # or -g for this machine only
sp install pack sandbox-3
```

Or install a single skill directly from this repo:

```bash
skills add anant-acog/sandbox-3 --skill aganitha-eda-live-viz
```

## Skills

- [`aganitha-eda-live-viz`](skills/aganitha-eda-live-viz/SKILL.md) — guides
  an EDA pass over a tabular dataset that ends in a live, interactive
  localhost page rather than a static report.
